# 无线协议入口

原文件管理协议与内容来源能力分开协商。原文件管理协议 2，内容导出能力 protocol=1；sourceReads 和 snapshotDownloads 用来判断独立只读来源与固定副本支持，不仅按应用版本判断。

当前已实现路由、状态码和范围见 [技术方案第 15、16 节](../content-export-technical.md)。前文拟定接口属于目标设计，不能直接作为已实现接口调用。

变更接口时同时更新 Android 路由、Mac DTO 与错误映射、兼容性测试及此处链接的实际契约；新增能力优先采用可选字段。禁止把真实令牌、设备指纹、来源 URI 或访问地址放入协议示例。
