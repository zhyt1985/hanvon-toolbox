# 内容导出模块功能设计

版本：0.1\
日期：2026-11-19\
状态：功能设计；基础实现与未完成范围见[开发进展](content-export-progress.md)\
适用基线：macOS 26、N10 Plus N10Q464、Android 11、固件 1.00.88、伴侣 0.5.0

本模块将电纸书上的笔记、便签、书信和语音收集到 Mac，提供可识别的内容列表、批量导出、来源记录和导出校验。USB 与 Wi-Fi 都是正式接入方式；是否可导出取决于来源授权和格式能力，不以连接方式替代格式支持。

首版交付笔记索引、选中笔记的原始资料包、来源目录原始备份，以及设备端已导出文件的收集。完整笔记库备份在必需资源范围验证后启用。无线来源授权与恢复机制属于首版验收范围。便签独立分类、书信完整归档、正式录音及笔记页面转换，按样例验证结果逐项开放。

技术实现见[内容导出模块技术方案](content-export-technical.md)。

## 1. 用户目标与范围

### 1.1 主要场景

| 场景 | 用户期望 | 首版处理 |
|---|---|---|
| 带走会议笔记 | 在 Mac 按标题找到笔记，批量保存 | 笔记索引、原始资料包、已导出 PDF 收集 |
| 定期备份 | 知道哪些内容已备份、哪些发生变化 | 手动发起增量导出，保留历史版本，不跟随源删除 |
| 无线收集 | 配对一次后，在同一 Wi-Fi 下导出 | 单独授权来源目录，沿用原配对和自动重连 |
| 导出录音及文字 | 音频、转写文本、所属笔记一起保存 | 先完成正式录音样例验证，再开放识别能力 |
| 保存书信 | 信件正文、附件、收发信息完整归档 | 先验证本地来源或分享出口，不把缓存当完整信件库 |
| 导出途中断线 | 重连后继续，已完成内容不重复传输 | 绑定原来源与版本；可续传时继续，否则重新准备 |

### 1.2 首版不包含

- 向汉王应用回写笔记、恢复其数据库，或编辑设备端笔迹。
- 解锁加密内容、读取其他应用的私有数据、使用 Root 或以 USB 调试为前提。
- 登录汉王云账号、获取云端书信及录音，或推断未下载的云端内容。
- 自动进行 OCR、语音识别、AI 摘要，或把内容上传到外部服务。
- 在尚未识别页面结构时，承诺完整 PDF、可编辑笔迹或完整多媒体还原。
- 定时后台备份。首版通过用户主动操作发起；自动重连仅恢复已开始的任务。

## 2. 真机证据与能力边界

以下为 2026-11-18 在本机连接的 N10 Plus 上的观察，不代表所有 N10 型号或后续固件。

| 内容 | 已观察事实 | 尚未确认 | 产品行为 |
|---|---|---|---|
| 笔记索引 | notes/.database/HvNote.db 可读；NoteList 有 17 条记录，有标题、分类、时间和类型字段 | 各字段语义、稳定主键、页序、删除标记及新固件兼容性 | 经适配验证后显示笔记列表；识别失败时允许文件级收集 |
| 页面文件 | .image/.image2 的标识为 hvNtDt02；.psl 为 NPSL0001；.tra 为 hvnote09 | 完整笔迹、底纹、图像与页面顺序的解码方法 | 保留原始资料，不显示未经验证的 PDF 转换入口 |
| 缩略图 | 一个 .thumb 样本为 148×199 PNG | 其他版本与其他笔记是否一致 | 仅作为列表缩略图，不能作为整页高清输出 |
| 便签 | 笔记库有 noteType 字段，当前 17 条记录只有一种类型值 | 便签对应的值、独立存储位置及与草稿的关系 | 保留“未分类”，不猜测类型值含义 |
| 语音 | VoiceRecorder/note.db 含录音、文本、时长等字段；独立录音表和笔记库 RecAudio 表均为空 | 正式音频路径、文本结构、音频与笔记关联 | 显示“尚未完成来源验证”，不把 msc 下 WAV/PCM 当正式录音 |
| 书信 | hwsys/hvTalk/nim 下音频、文件、图片、视频缓存为空 | 消息索引、正文、完整附件及云端范围 | 显示验证状态，不宣称书信数量为零 |

检查采用顺序 MTP 复制，三个 SQLite 副本通过 quick_check；伴随 rollback journal 均为空，未在相应目录观察到 WAL。该结果不证明设备正在编辑时能取得原子快照。11 个临时样本已在检查后删除。

## 3. 导出类型

### 3.1 三种输出

| 输出 | 用途 | 包含内容 | 能力条件 |
|---|---|---|---|
| 原始资料包 | 留存单项或多项内容，便于后续解析 | 选中项的原始文件、必要关联资源、选中项索引、清单与校验值 | 来源可读、边界可枚举、读取稳定 |
| 已导出文件收集 | 在 Mac 阅读、播放和分享 | 设备端已生成的 PDF、图片、音频、文本，保持原始字节 | 用户选择的来源目录中确有这些文件 |
| 标准格式转换 | 直接从原始内容生成 PDF、图片或文本 | 经验证的完整页面、附件或转写内容 | 对应格式适配器及受控样例通过验收后开放 |

原始资料包不等于可回写恢复包。单项资料包只包含选中项需要的数据，不附带整个数据库或其他笔记标题。另设“完整笔记库备份”，明确告知会包含整个索引、分类及所选备份范围内的资源。

标准格式转换尚未支持时，按钮显示具体原因及替代操作，例如“当前版本支持原始资料包；可在电纸书生成 PDF 后收集”。

### 3.2 输出组织

每次操作生成独立目录，默认名称为“内容导出 日期 时间 短任务号”。同名目录不会覆盖。

~~~text
内容导出 …/
  manifest.json
  result.json
  阅读说明.txt
  items/
    笔记标题--短内容号.hanvonexport/
      item.json
      raw/
      attachments/
    已导出文件--短内容号/
      files/
  library/                  仅完整笔记库备份出现
~~~

.hanvonexport 在首版是普通文件夹，不注册为隐藏内部结构的系统文件包。文件名使用可读标题和短内容号；无标题时使用“未命名笔记”，原始标题保存在 item.json。保留原始相对路径的准确拼写，不用清理后的显示名反向定位源文件。

完整笔记库备份采用独立任务，范围必须覆盖已识别的索引、分类、笔记目录及必需共享资源；未发现或无法读取的部分列入缺失报告。存在缺失时不得标为“完整备份成功”。

## 4. 连接与来源授权

### 4.1 USB

沿用文件传输模式及当前 MTP 连接，不要求 USB 调试。首次扫描仅访问已识别的候选来源，展示将读取的内容范围；扫描笔记列表时会读取索引及必要元数据。

导出前提示保存笔记并退出编辑、结束录音。只读访问源文件，不更名、移动、删除或修复设备上的数据库。部分设备未公开来源目录时，显示“USB 未公开此来源”，不显示为空。

### 4.2 Wi-Fi 无线管理

沿用已有设备指纹、配对、钥匙串与自动发现。伴侣新增“内容来源”设置，与原来的可读写文件管理目录分开。

用户在设备端为笔记来源、录音来源、已导出文件来源分别授权；优先请求只读权限，并选择允许访问该来源的已配对 Mac。系统选择器无法授权的来源，显示限制及替代路径。当前“我的下载”的授权不扩展到 notes 或其他同级目录。

撤销内容来源授权立即阻止新的读取及后续分块请求，并清理受影响的设备端暂存；已导出到 Mac 的文件由用户管理。重新授权同一路径也需刷新来源版本，旧任务不得静默读入新内容。

### 4.3 原厂 Wi-Fi 传书

仅收集原厂服务公开的文件。不承诺笔记数据库访问、来源授权、整库备份和新增的快照续传。界面明确区分“Wi-Fi 传书”和“无线管理”。

## 5. 界面与操作

### 5.1 入口与布局

工具栏增加“内容导出”，打开独立窗口，保留主窗口双栏文件管理的位置与选择。

~~~text
内容导出                          N10 Plus · 无线管理 · 已连接
[全部] [笔记] [便签] [书信] [语音] [已导出文件]
[搜索标题…] [分类] [时间] [导出状态]       [刷新] [管理来源]

内容列表                              检查器
□ 标题  类型  修改时间  页数/时长        缩略图/格式能力
□ …                                   来源、附件、缺失项
                                      上次导出与版本

已选 3 项（筛选外 1 项）               [导出所选…]
[导出记录] [完整笔记库备份…]
~~~

列表按实际能力显示字段；未知页数、时长和时间显示“—”。来源缺失、未授权、未完成适配与“已扫描且无记录”使用不同状态。

搜索仅作用于已加载的标题和已验证元数据，首版不搜索笔记正文。批量选择支持“选择当前筛选”“取消选择当前筛选”；筛选变化不清空已选项，底部始终显示所有已选项及筛选外数量。

### 5.2 来源管理

每个来源显示设备、连接方式、来源用途、可读范围、授权状态及最近扫描时间。Mac 可发起设置引导，实际目录选择和新增访问授权在电纸书上完成。

来源状态包括：可用、需授权、授权已撤销、目录不存在、设备未公开、格式待适配、暂离线。界面不显示原始 content URI、数据库表名和配对令牌。

### 5.3 导出步骤

1. 选择内容。详情区展示来源、可用输出、关联附件和已知缺失。
2. 选择导出方式及 Mac 目标目录。仅启用当前可验证的格式。
3. 预览计划：项目数、输出方式、预计大小或“待计算”、历史重复、缺失项及来源稳定性要求。
4. 点“开始导出”。需要准备设备端快照时先显示准备进度，不能提前显示文件传输完成。
5. 在任务记录中查看准备、下载、校验与发布结果。失败项目可单独重试，其他项目继续。
6. 完成后提供“在访达中显示”和逐项结果报告。

### 5.4 增量与重名

- 已有导出只有在来源身份、内容身份、完整资源指纹和输出配置均一致，且原输出仍存在并校验通过时，才可跳过。
- 修改时间仅用于快速筛选，不能单独作为内容一致的依据。
- 内容有变化时生成新版本；不覆盖旧版本、不因设备端删除而删除本机副本。
- 相同标题、相同秒级时间及大小写差异都不得导致文件覆盖。
- 首版不在 USB 与 Wi-Fi 之间自动切换同一未完成任务。

### 5.5 任务与重连

内容导出记录使用单独任务模型，在“传输记录”中增加“内容导出”页签，并从导出窗口直接进入。任务使用现有连接状态与调度资源，避免两个 USB 会话争抢设备。

暂停保留可恢复的任务和分块；取消清理该任务临时数据，保留已完成输出。设备离线时，将远端清理记录为待处理。恢复时重新核对设备、来源授权版本和源内容版本。

无线可用快照支持跨启动续传；USB 首版按文件重新下载、跳过已校验完成文件。快照过期或来源变化时，提示重新准备，不能沿用旧偏移拼接新版本。

## 6. 异常与提示

| 情况 | 行为与文案要点 |
|---|---|
| 笔记仍在编辑或录音未结束 | “来源仍在变化，请保存并退出编辑后重新准备” |
| 设备休眠 | “电纸书暂离线，唤醒后将尝试恢复已开始的任务” |
| 用户主动暂停或断开 | 保持暂停，不自动启动新扫描 |
| 授权撤销 | “此内容来源的授权已撤销，请在电纸书上重新授权” |
| 未知格式或新固件 | 保留文件级导出能力，不把未知类型强行归为笔记或便签 |
| 加密内容 | 显示受保护；不索取密码、不尝试绕过限制 |
| 附件缺失 | 明确标记缺失，不能提示“完整导出” |
| 部分项目失败 | 显示完成、跳过、失败、取消各自数量；保留成功项目 |
| 本机或设备空间不足 | 准备前核算；中途不足则保留可恢复进度并提示所需空间 |
| SHA-256 不匹配 | 不发布目标文件，保留失败说明，重新获取该资源 |
| 目标目录无权限或已移动 | 请求重新选择本机目标，重新生成计划，避免旧任务写到错误位置 |

## 7. 数据与隐私

内容默认只在设备与这台 Mac 之间传输。来源只读；首次扫描须说明会获取索引元数据，缩略图按需读取，不后台下载所有正文或录音。

设置提供“缓存管理”，区分可恢复临时数据、本地列表元数据和正式导出文件。清理缓存不等于删除正式导出文件，也不撤回其他已保存副本。

本机元数据与临时文件采用私有目录和文件权限，不声明额外的内容加密能力。诊断日志不记录标题、正文、音频、联系人、原始 URI、配对码或令牌。来源位置、标题和关联信息只写入必要的私有索引和用户选择的导出包。

## 8. 交付阶段

| 阶段 | 交付物 | 完成门槛 |
|---|---|---|
| M0 来源与格式验证 | 受控样例、字段与格式档案、USB/Wi-Fi 来源可读性结论 | 新建笔记、便签、书信、独立录音及笔记录音逐一对照；未知项保留限制 |
| M1 Mac 导出基础 | 独立窗口、USB 笔记索引、资料包、来源备份、文件收集、记录与校验 | 必要隐藏索引与资源检查通过；同名冲突、取消、重开及源变化测试通过；完整库备份按能力门槛开放 |
| M2 首版无线闭环 | 多来源只读授权、按 Mac 授权、快照与续传、配对兼容 | 不影响原文件管理；后台、休眠唤醒、授权撤销、跨启动恢复真机通过 |
| M3 内容类型扩展 | 已验证的便签分类、语音和书信适配 | 分别取得完整样例与来源证据；可按类型独立发布 |
| M4 页面转换 | 版本化页面解码、PDF/图片及转换质量报告 | 多页、底纹、笔刷、橡皮、附件、旋转及未知版本拒绝测试通过 |

首版完成指 M1 与 M2 均达到验收标准；M0 是相关能力开放的前置条件。M3、M4 未通过的能力在 UI 中保持不可用，并提供设备端导出后收集的替代路径。

## 9. 验收标准

- USB 与已授权的无线来源能够得到同一受控笔记集的相同内容清单；不依赖 USB 调试。
- 不把现有 17 条真实记录作为可公开的自动化测试夹具。回归使用新建、无隐私内容。
- 索引中未识别的类型保留为未分类，未知时间单位和页数不猜测显示。
- 单项资料包不包含未选笔记的正文、标题或数据库记录；整库备份有独立范围提示。
- 每个发布资源有大小及 SHA-256；缺失、变化或不一致时不能标为完整成功。
- 便签、书信、语音的“无记录”必须来自成功且已适配的扫描，不能由未授权或未适配推断。
- 暂停、重开、断网、休眠唤醒、服务换端口后，恢复行为与连接能力一致；同一任务不混入其他来源版本。
- 撤销授权、来源替换、错误设备、错误存储和损坏缓存均停止继续读取。
- 导出前后设备源文件内容保持一致；不会修改、删除、修复原应用数据。
- macOS 键盘操作、VoiceOver 状态描述、窄窗口、长标题和筛选外选择提示通过界面验收。
